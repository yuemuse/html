HTML セマンティック

このドキュメントは日本語で、主要なセマンティック（意味づけされた）HTML要素の説明、使い方、例、ベストプラクティスをまとめたものです。

目次

  1. ランドマーク要素（header, nav, main, footer, aside）
  2. セクショニング要素（section, article）
  3. テキストレベルのセマンティクス（strong, em, mark, small, time, address）
  4. メディアと補助要素（figure, figcaption, picture, img）
  5. インタラクティブ（details, summary, dialog, progress, meter）
  6. アクセシビリティとSEOのポイント
  7. まとめ（チートシート）

ランドマーク要素

ランドマーク要素はページ内で構造的に重要な領域を示します。支援技術（スクリーンリーダー等）はこれらを利用してページを把握します。

<header>

ページやセクションの導入部。ロゴや見出し、グローバルなナビゲーションを含めることが多い。

<header>
  <h1>サイト名</h1>
  <nav>...</nav>
</header>

<nav>

ナビゲーション用のリンク集合。ページ内で複数のナビがある場合は、目的に応じて使い分ける（例：メインナビ、フッターナビ、サイドナビ）。

<main>

文書の主要なコンテンツ。ページごとに1つだけ使用する（複数は避ける）。

<aside>

主要コンテンツに対する補助的情報（サイドバー、関連リンク、広告など）。

<footer>

フッター領域。著作権情報、連絡先、二次的なナビゲーションなどを置く。

<body>
  <header>...</header>
  <main>
    <article>主要な記事</article>
    <aside>関連情報</aside>
  </main>
  <footer>...</footer>
</body>

セクショニング要素

ドキュメントの論理的な区切りに使います。適切に使うと見出し階層（アウトライン）が明確になります。

<section>

トピックやテーマで区切られた一般的なセクション。通常は見出し（h1〜h6）を持つ。

<article>

独立して配布・再利用できるコンテンツ（ブログ投稿、ニュース記事、コメント等）。

<h1>〜<h6>（見出し）

見出しはコンテンツの階層を示す。HTML5では見出しはsectioningコンテキストに基づいてネストされる。

<article>
  <h2>記事タイトル</h2>
  <section>
    <h3>セクション見出し</h3>
    <p>本文...</p>
  </section>
</article>

テキストレベルのセマンティクス

<strong> と <em>

<strong>は重要性を、<em>は強調を示します。スクリーンリーダーはそれぞれを異なる方法で読み上げることがあります。

<mark>

ハイライト（検索結果の該当箇所など）。

<small>

補足や小さな注記（著作権表示など）に使用。

<time>

日時を示す。datetime属性を付けると機械可読性が高まる。

<time datetime="2025-11-19">2025年11月19日</time>

<address>

連絡先情報（著者や組織のコンタクト）。必ず連絡先に限定して使う。

メディアと補助要素

<figure> と <figcaption>

図版（画像、図、コードスニペットのスクリーンショットなど）とそのキャプションをグループ化する。

<figure>
  <img src="example.jpg" alt="説明文" />
  <figcaption>図1: 説明コメント</figcaption>
</figure>

<img> と alt 属性

alt属性は必須。画像の意味を短く説明する。装飾的な画像は空文字（alt=""）にする。

インタラクティブ要素

<details> と <summary>

折りたたみ可能な領域。アクセシビリティに配慮された簡易な開閉UIを提供する。

<details>
  <summary>もっと読む</summary>
  <p>ここに隠された詳細情報</p>
</details>

<dialog>

モーダルダイアログ。ブラウザサポートを確認の上、必要に応じてフォールバックを用意する。

<progress> と <meter>

進捗や目盛りを表す要素。機械可読かつ視覚表現が標準化されている。

アクセシビリティとSEOのポイント

  • 意味のある要素を使うと、スクリーンリーダーや検索エンジンがコンテンツを正しく解釈しやすくなる。
  • <main>はページに一つだけ。<header>や<footer>はセクション単位にも使える。
  • 見出しは順序を守る（h1→h2→h3...）。スタイリングで順序を壊してはいけない。
  • 画像には必ず適切な alt を付ける。装飾画像は空の alt にする。
  • フォーム要素にはラベルを関連付ける（<label for="..."> または aria-label）。
  • ランドマークに role 属性を付ける必要は通常ないが、複雑なケースでは ARIA を補助的に使う。
注意：セマンティック要素は見た目を変えるものではなく、構造と意味を伝えるためのものです。CSSで自由に見た目を調整してください。

チートシート（よく使う要素）

要素意味使いどころ
<header>導入・ヘッダーサイトヘッダ、セクションのヘッダ
<nav>ナビゲーション主要リンク集合
<main>主要コンテンツページの中心内容（1ページ1つ）
<article>独立した記事ブログ投稿、ニュース記事
<section>セクショントピックごとの区切り
<aside>補助情報サイドバー、関連情報
<footer>フッター著作権、補助ナビ
<figure>/<figcaption>図とキャプション画像＋説明
<details>/<summary>折りたたみFAQなど

ベストプラクティスまとめ

  1. 意味に合った要素を使う（見た目だけでタグを選ばない）。
  2. 見出しの階層を自然に保つ。
  3. アクセシビリティ（alt, label, roleの適切な利用）を忘れない。
  4. マークアップはコンテンツの構造を説明することを優先する。

実践例：簡単なブログページ（サンプル）

<!doctype html>
<html lang="ja">
<body>
  <header>
    <h1>ミニブログ</h1>
    <nav><a href="/">ホーム</a> | <a href="/about">このサイトについて</a></nav>
  </header>

  <main>
    <article>
      <h2>記事タイトル</h2>
      <p>投稿日：<time datetime="2025-11-19">2025年11月19日</time></p>
      <figure>
        <img src="photo.jpg" alt="風景写真" />
        <figcaption>自然の風景</figcaption>
      </figure>
      <p>本文の段落...</p>
    </article>

    <aside>
      <h3>サイドバー</h3>
      <p>プロフィールやリンク</p>
    </aside>
  </main>

  <footer><small>© 2025 例のサイト</small></footer>
</body>
</html>
