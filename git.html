Git コマンド一

基本操作

  • git init — 新しい Git リポジトリを作成する。
  • git clone <URL> — リモートリポジトリをローカルにコピーする。
  • git status — 現在の変更状況を確認する。
  • git add <ファイル名> — 変更をステージに追加する。
  • git add . — 全ての変更をステージに追加する。
  • git commit -m "メッセージ" — ステージされた変更をコミットする。
  • git push — ローカルのコミットをリモートへ送信する。
  • git pull — リモートの変更を取得してマージする。

ブランチ操作

  • git branch — ブランチ一覧を表示する。
  • git branch <名前> — 新しいブランチを作成する。
  • git checkout <ブランチ名> — 指定のブランチに切り替える。
  • git checkout -b <名前> — 新ブランチを作成してそのまま切り替える。
  • git merge <ブランチ名> — 指定ブランチを現在のブランチにマージする。
  • git branch -d <名前> — ブランチを削除する。

履歴・差分

  • git log — コミット履歴を表示する。
  • git log --oneline — 簡易表示のコミット履歴。
  • git diff — 変更内容を確認する。
  • git show <コミットID> — 特定コミットの詳細を表示する。

リセット・修正

  • git reset --hard <コミットID> — 指定のコミットまで履歴と作業状態を戻す。
  • git reset --soft <コミットID> — コミットだけ巻き戻し、変更は残す。
  • git revert <コミットID> — 特定コミットを打ち消す新しいコミットを作成する。
  • git restore <ファイル> — 変更を元に戻す（Git 2.23 以降）。

リモート操作

  • git remote -v — リモート一覧を表示。
  • git remote add origin <URL> — リモートリポジトリを追加する。
  • git fetch — リモートの変更を取得（マージはしない）。
