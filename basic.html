HTML 基本タグまとめ（日本語説明）

Webページの構造を作成する上で必ず知っておきたい基本タグの説明とサンプルです。

1. <html> / <head> / <body>

HTML文書全体の構造を定義するタグです。 <head> はメタ情報、<body> は画面に表示される内容を含みます。 

<html>
  <head>
    <title>ページタイトル</title>
  </head>
  <body>
    ここにページの内容
  </body>
</html>

2. 見出しタグ（<h1> ～ <h6>）

ページ内のタイトルやセクションを表します。数が小さいほど重要な見出し。

<h1>最も重要なタイトル</h1>
<h2>セクションタイトル</h2>
<h3>小さい見出し</h3>

3. 段落タグ（<p>）

文章を段落として表示します。

<p>これは段落の例です。</p>

4. リンク（<a>）

別ページへのリンクを作ります。 href 属性にURLを設定します。 

<a href="https://example.com">リンクを見る</a>

5. 画像（<img>）

画像を表示します。 src が画像の URL、alt が代替テキストです。 

<img src="image.jpg" alt="説明文" />

6. リスト（<ul>, <ol>, <li>）

箇条書きを作成します。 <ul> は順序なし、<ol> は番号付き。 

<ul>
  <li>リンゴ</li>
  <li>バナナ</li>
</ul>

<ol>
  <li>ステップ1</li>
  <li>ステップ2</li>
</ol>

7. テキスト装飾（<strong> / <em> / <span>）

<strong> は重要（太字）。

<em> は強調（斜体）。

<span> はインライン要素を包むための汎用タグ。

<p>これは <strong>重要</strong> な文です。</p>
<p>これは <em>強調</em> です。</p>
<p><span style="color: red;">赤文字</span> の例。</p>

8. 区切り・コンテナ（<div> / <section> / <header> / <footer>）

ページを構造化するためのタグ。 <div> は汎用、<section> や <header> は意味を持つ構造タグ。 

<header>ヘッダーエリア</header>

<section>
  <h2>セクションタイトル</h2>
  <p>内容...</p>
</section>

<footer>フッター</footer>

9. 表（<table> / <tr> / <td> / <th>）

表形式データを表示します。

<table border="1">
  <tr>
    <th>名前</th>
    <th>年齢</th>
  </tr>
  <tr>
    <td>太郎</td>
    <td>20</td>
  </tr>
</table>

10. フォーム（<form> / <input> / <textarea> / <button>）

ユーザー入力を受け取るためのタグ。

<form action="/submit" method="post">
  名前: <input type="text" name="name" /><br>
  コメント: <textarea name="comment"></textarea><br>
  <button type="submit">送信</button>
</form>
